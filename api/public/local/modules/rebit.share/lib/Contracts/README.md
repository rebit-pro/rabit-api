# Предметные межмодульные контракты

Каталог: `rebit.share/lib/Contracts/<Domain>/`.
Namespace: `Rebit\Share\Contracts\<Domain>`.

Здесь размещаются публичные интерфейсы, DTO и события предметного взаимодействия: например, `Order`, `Payment`, `Media`. Подкаталоги и PHP-классы добавляются в волне соответствующего сценария; этот README не объявляет их реализованными.

Реализация, UseCase и DI находятся в модуле-поставщике. Контракт не содержит SQL/ORM, инфраструктурные адаптеры и бизнес-реализацию, не возвращает Bitrix Result или внутренний ReadModel. Внутренние интерфейсы репозиториев, порты и DTO не выносятся сюда автоматически.

Общие технические контракты остаются в [`lib/Application/Contract/`](../Application/Contract/README.md): кеш, транспорт сообщений, файловые операции и разрешение токена. Определяющим является смысл контракта: передача сообщения — техническая возможность; событие заказа — предметный контракт.
