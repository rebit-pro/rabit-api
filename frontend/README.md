# Frontend MoreFoto

Vue 3, TypeScript и Vuetify. С A8 исходники находятся в `frontend/` репозитория RaBit API. Оригинальный каталог MoreFoto сохранён; история его демонстрационных выпусков — [здесь](../docs/waves/a8/frontend-demo-history.md).

В реальном режиме работают вход/выход, профиль сотрудника и каталог организатора. Учётная запись принадлежит Bitrix, роль/разрешения возвращает `GET /api/v1/me`. Товары сохраняются в БД через COM-01–03. Остальные экраны кабинета подключаются в своих волнах. Публичные галерея, корзина, оформление и оплата в live-режиме ведут на страницу недоступного раздела до подключения соответствующих функций. Продажа, оплата, оригиналы фотографий и внешняя CAPTCHA не входят в проверку A8.

## Настоящий браузерный E2E

Из корня репозитория в Linux/WSL:

```sh
make test-e2e
```

Команда устанавливает зависимости из lockfile, выполняет проверки, собирает frontend без mocks, создаёт отдельные Bitrix/FPM/MySQL/nginx и запускает Chromium. Рабочий `.env` не читается. Подробности, необходимые образы и визуальная проверка — [A8](../docs/waves/a8/README.md).

Для обычной разработки:

```sh
npm ci
npm run dev
```

`VITE_API_MOCKS_ENABLED=false` — настоящий API. `VITE_API_URL` — origin API или пустая строка для same-origin reverse proxy. Все пути имеют вид `/api/v1/...`; nginx сохраняет префикс. Для локальной разработки с отдельным API задайте его origin и разрешённый CORS origin на backend.

## Проверки frontend

```sh
npm run check
npm run test:commerce
npm run build
npm run test:e2e:run
```

Последняя команда запускает существующий Cucumber-регресс **demo-режима**. Он проверяет UI и локальную модель; его hooks запрещают обращения к настоящему API. Это отдельный набор, который не заменяет `make test-e2e`.

Для изучения будущих интерфейсов можно явно включить `VITE_API_MOCKS_ENABLED=true`. В этом режиме пользователи, товары и остальные данные демонстрационные, хранятся в браузере под `morefoto:demo:`. Live-сессии и черновики используют `morefoto:live:`. Отчёты, traces, видео и тестовые токены не включаются в Git.
