# OPS — путеводитель прогона stage и база знаний

> Оперативная задача вне графа волн: ветка `codex/ops-stage-run-guide`, без продуктового кода.

## Цель и контекст

Пользователь хочет пройти весь путь ролей на `app.morefoto36.ru`: организатор (он и Алёна), куратор (Рита), родитель — до
ссылки на галерею и заказа, и держать инструкцию у себя на сервере. Раздел `/guide/` станет базой знаний команды.
Инструкция сначала опубликована как страница claude.ai, затем пользователь выбрал отдельную статическую страницу без входа.

## Scope

- `frontend/public/guide/index.html` — главная базы знаний со списком статей.
- `frontend/public/guide/stage-run/index.html` — путеводитель: роли, 9 этапов с отметками, поля для данных прогона
  (команда, созданные записи, ссылка на галерею, заказ, заметки), состояние оплаты ЮKassa, частые проблемы.
- Поля и отметки хранятся в `localStorage` браузера; внешних запросов нет (системные шрифты).
- Выкладка frontend-only релиза после merge — отдельным решением пользователя.

## Вне scope

- Страница внутри кабинета с доступом по ролям и серверным хранением полей (будущая база знаний по ролям).
- Включение `MOREFOTO_CHECKOUT_ENABLED` на stage — отдельное действие на сервере.
- Оплата ЮKassa (волна G1).

## Решения, зависимости, риски

- OPS-GUIDE-DEC-01: отдельная статическая страница без входа, адрес `/guide/stage-run/` (выбор пользователя 25.09.2026).
  Страница доступна всем, кто знает адрес; nginx отдаёт `X-Robots-Tag: noindex, nofollow`, страница дублирует meta robots.
  В тексте нет секретов, имён переменных окружения и ключей.
- Nginx `location /` c `try_files $uri $uri/ /index.html` отдаёт файлы `public/guide` раньше SPA — правка конфигурации
  не нужна.
- Риск: сборка frontend из актуального `main` выложит и слитый, но не выложенный PR #76 (#72/#73, только frontend).
  Выкладка — отдельным решением пользователя.
- Шаги и названия кнопок сверены с кодом `main` 4621ad9: галерея открывается только после «Отметить передачу»
  (`UF_SENT_AT`), «Оформить заказ» зависит от `purchaseEnabled`, маршрут оплаты `demoOnly`.
