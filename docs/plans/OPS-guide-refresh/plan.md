# OPS — актуализация базы знаний /guide/ и просмотр скриншотов

> Продолжение [OPS-guide-knowledge-base](../OPS-guide-knowledge-base/plan.md) (PR #95, выложен 26.09.2026). Оперативная
> задача вне графа волн, ветка `codex/ops-guide-refresh`.

## Цель и контекст

После выкладки базы знаний на сайт попали переделанные экраны: юридические документы и плашка cookie, страница входа
с обращением в MAX, компактные таблицы (#92, #103), карточка кадра (#147/148), «ZIP по детям» (#150), путь к галерее
(#127), группа со страницы учреждения (#105), электронные фотографии в заказе (J1), вопросы куратору (K3), тексты
оформления (#109/#110). Скриншоты базы сняты на `d8caca4` и устарели. Кроме того, скриншот открывается как голая
картинка в новой вкладке, без кнопки «Закрыть» и листания.

## Scope

- Переснять все скриншоты статей организатора, куратора и родителя на стенде текущего `main` (`173035e`, приложение
  совпадает с выложенным `9a4cce6`), добавить снимки новых возможностей (ZIP по детям, электронные фото, вопросы).
- Актуализировать тексты статей под новый интерфейс: названия кнопок, пунктов меню, новые обязательные действия.
- Просмотр скриншотов поверх страницы (аналог Fancybox): крестик «Закрыть», Esc, клик по фону, кнопка «Назад» телефона,
  листание стрелками/клавишами/свайпом, счётчик и подпись.

## Вне scope

- Изменения приложения, nginx, маршрутов SPA; база знаний внутри кабинета.
- Внешние библиотеки: страницы остаются статическими без внешних запросов (OPS-KB-DEC-01).

## Решения, риски

- OPS-KBR-DEC-01: просмотрщик — собственный код на `<dialog>` в общем `guide.js` (~150 строк JS+CSS) вместо Fancybox:
  нет зависимостей и внешних запросов, фокус и Esc даёт браузер. Без JS ссылка по-прежнему открывает картинку.
- OPS-KBR-DEC-02: база скриншотов и выкладки — `main` `173035e`; выкладка frontend-only, образ от живого frontend
  в момент выкладки + `frontend/public/guide/` из ветки (правило прошлой итерации).
- OPS-KBR-DEC-03: снимки там, где сюжет уже прошёл нужное состояние (c03, o17, o18b), и футер без опубликованных
  реквизитов (p05, p05b, p06; на сайте продавец не опубликован) сняты с подменой ответов API в браузере (`page.route`),
  POST на этих экранах заблокированы. Раздела вопросов у куратора в кабинете нет — куратор отвечает в MAX, снимок c09
  не нужен; шаг описан текстом.
- Риск: параллельные сессии выкладывают новые экраны — перед выкладкой сверить живой образ.

## Критерии приёмки

- Скриншоты совпадают с интерфейсом выложенной версии; тексты шагов называют существующие кнопки и пункты меню.
- Скриншот открывается поверх статьи, закрывается крестиком, Esc, кликом по фону и кнопкой «Назад»; листаются все
  скриншоты статьи; работает на 390 px и 1280 px, в светлой и тёмной теме.
