# OPS-login-feedback — информация и обратная связь на странице входа

## Цель и контекст

Страница `/login` показывает только логотип и карточку входа: непонятно, что это за сервис, и некуда написать, если
войти не получается. Нужно добавить шапку, короткую информацию о кабинете и форму обратной связи.

Решение пользователя (2026-09-25): обращения со страницы входа уходят **в ту же группу кураторов MAX**, что и вопросы
K3 (`MOREFOTO_SUPPORT_MAX_CHAT_ID`); Telegram и отдельные каналы не используются.

Задача вне графа волн: ветка `codex/ops-login-feedback`, план `docs/plans/OPS-login-feedback/`.

## Scope

- Backend `morefoto.support`: новый тип беседы `guest` — обращение без аккаунта и без галереи.
  - `POST /api/v1/public/feedback` (JSON `name`, `contact`, `message`, заголовок `Idempotency-Key`) → `202 {number}` — номер обращения для гостя.
  - Беседа `guest` + реплика `pending` в существующем outbox; доставка в MAX тем же consumer/dispatcher (повторы,
    очередность, ожидание при ненастроенном боте).
  - Контекст сообщения в MAX: «Страница входа · контакт: …»; подсказка «Ответьте по указанному контакту».
  - Правила: имя и текст — `QuestionTextPolicy`; контакт — email или телефон (от 10 цифр), до 120 символов.
  - Защита: повтор с тем же ключом не создаёт второе обращение, другой текст с тем же ключом — 409;
    не более `GUEST_QUESTIONS_PER_HOUR` обращений со страницы входа в час на весь сайт → 429.
  - Миграция `migrations.foundation`: CHECK-ограничения `mf_support_question`/`mf_support_message` допускают `guest`.
- Frontend:
  - `AccessShell` получает необязательный слот `aside`; страница входа — шапка (логотип + «Написать нам»),
    карточка входа и блок «Что это за кабинет» (для кого, родителям вход не нужен, как получить доступ).
  - Диалог обратной связи: имя, контакт, сообщение; отправка с `Idempotency-Key`, понятные ошибки, экран «Отправлено».

## Исключено

- Ответ куратора гостю через сайт: гость не получает ключ беседы, куратор отвечает по контакту. Ответ «Ответить» в MAX
  на сообщение гостя не сохраняется (`questionByOutgoingMid` ищет только реплики `parent`/`staff`).
- Остальные страницы доступа (`/access/*`) не меняются, кроме общей обвязки `AccessShell` (слот необязательный).
- Telegram, email, отдельный канал, CAPTCHA.

## Решения и риски

- Переиспользуем outbox K3 вместо синхронной отправки: не теряем обращение при сбое MAX или ненастроенной группе.
- Глобальный лимит в час: спамер может занять лимит на час; для текущего трафика приемлемо, при необходимости —
  лимит по IP отдельной задачей.
- Миграция меняет CHECK-ограничения таблиц K3; откат возвращает прежние, если гостевых бесед нет.
- Зависимость: K3 (`morefoto.support`, `Version20260925150001`) слит в `main` (caa37b6).

## Критерии приёмки

- На `/login` есть шапка с логотипом и кнопкой «Написать нам», блок о кабинете; вход работает как раньше.
- Обращение из диалога создаёт реплику `pending` и доставляется в группу кураторов MAX с контактом.
- Повтор запроса не дублирует обращение; превышение лимита даёт понятную ошибку.
- Desktop и mobile без горизонтального скролла.
