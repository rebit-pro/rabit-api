# OPS - точный фильтр ребёнка в публичной галерее

## Цель и границы

При выборе кода ребёнка показывать только его серию: A отдельно от AA/AB/BA, B от BB, C от CC; правило едино для всех кодов. Сохранить все серии, поиск конкретного кадра и прежние коды серий A001. Галерея уже загружена и готовится к запуску. Пользователь просит исправление и публикацию.

Меняется только клиентский выбор фотографий. Загрузка, раскладка, оригиналы, БД, заказы, платежи, доступы и API не меняются. E2E не запускать согласно действующему указанию пользователя.

## Решение и карта компонентов

- useGallery: URL и состояние просмотра; computed использует чистый filterGalleryPhotos.
- filterGalleryPhotos: точное совпадение GalleryChild.code; если серии нет, точное совпадение GalleryPhoto.code. Пустой фильтр возвращает все серии. Регистр и пробелы нормализуются.
- GalleryFilters/GalleryGrid/PhotoViewer: существующие контракты, без изменений.
- Сохраняются данные назначений выбранной серии, в том числе для общих кадров.
