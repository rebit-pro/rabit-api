# Issues #147 и #148 — карточка кадра, выбор всех, пагинация, сдвиг фона у попапов

## Цель

Устранить UX-замечания ручной проверки stage 2026-09-26:
- #147: в карточке кадра разъезжаются действия, подпись чекбокса дублирует код, кадры без ребёнка незаметны, нет
  «Выбрать все», активная страница пагинации — сплошной квадрат без номера;
- #148: при открытии попапа фон сдвигается на ширину полосы прокрутки.

## Scope (только frontend)

1. Карточка: чекбокс без текста в левом верхнем углу превью (`aria-label` «Выбрать кадр …»); полоса снизу с кодами
   и именем файла; справа иконки «Сделать обложкой» (звезда) и «Удалить кадр» с подсказками; бейдж «Обложка» на превью.
2. Кадр без ребёнка: рамка и полоса в тоне предупреждения, иконка вместо текста «Без ребёнка» (текст — для диктора).
3. Панель выбора: «Выбрать все на странице» и «Снять выбор».
4. Пагинация: активная страница с обычной подложкой активного состояния и цветом primary (глобально).
5. Попапы: `scrollbar-gutter: stable` у `html` и отключение компенсации Vuetify `padding-inline-end`.

## Вне scope

- Выбор всех кадров группы на всех страницах (выбор по-прежнему в пределах страницы).
- Другие экраны с карточками.

## Решения

- DEC-1: имя кнопки обложки остаётся «Сделать обложкой» (на него опираются E2E), у текущей — «Обложка группы».
- DEC-2: причина чёрного квадрата — Vuetify тонирует активную страницу `--v-border-opacity`, а тема ставит его в 1;
  переопределение в `_base.scss` с большей специфичностью.
- DEC-3: цена исправления сдвига — постоянное место под полосу прокрутки (15 px) на страницах без прокрутки в
  браузерах с классической полосой.
