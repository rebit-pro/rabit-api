# Issue #154 — «Проверить» неактивна без объяснения: обычную группу держит список сотрудников

## Цель и контекст

Стенд, 2026-09-27: у «Средней группы» (обычная) путь к галерее выглядит пройденным, кнопка «Проверить» в «Ссылках и
сроках» неактивна, причина не видна. Сервер добавляет `staffRequestsPending` любой группе с неразобранными строками
списков сотрудников, а `galleryPath.ts` показывает шаг списков только группам сотрудников.

- Issue: [#154](https://github.com/rebit-pro/rabit-api/issues/154). Ветка `codex/issues-154-staff-step` от `main` `173035e`.
- Не продуктовая волна: `docs/waves/graph.json` не меняется.

## Scope

- `galleryPath.ts`: шаг «Проверить списки сотрудников» — у группы сотрудников или при `staffRequestsPending`;
  незнакомый интерфейсу код проблемы — текстом на шаге «Проверить ссылку», а не теряется.
- `LinksScreen.vue`: у неактивной «Проверить» — всплывающая причина (подсказка текущего шага).
- Тесты: `tests/ui/gallery-path.test.mjs`; live — проверка в `z-links-preparation` не нужна, если нет сценария
  с обычной группой в списке сотрудников (см. тест-кейсы).

Исключено: изменение серверного правила (оно верно: неразобранный список меняет состав группы).
