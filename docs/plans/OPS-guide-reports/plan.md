# OPS: база знаний — раздел «Отчёты о продажах»

## Цель

В базе знаний `/guide/` появляется статья о новом разделе кабинета «Отчёты» (E10): кто что видит, как читать отчёт и статусы детей, как скачать PDF. Статьи ролей и стартовая страница ведут на неё.

## Контекст

- E10 (PR #221 + OPS #224) выложена на stage 25.10.2026, релиз `main-20261025141159-40b44df`. Владелец: «Доработай базу знаний с учетом нового раздела. Сделай деплой на сервер».
- База знаний — статические страницы `frontend/public/guide/`, скриншоты WebP 1280×800, лайтбокс в `guide.js`. Прошлое обновление — OPS-guide-refresh (PR #158).
- Старые статьи частично устарели после E7/E8/F3/J4/D4 — это #188, вне scope.

## Решения

- **Скриншоты кабинета** — живые экраны текущего frontend (`main`), отрисованные в Chromium с подменой API (Vite live + Playwright `page.route`).
  - Данные демонстрационные: «Детский сад № 15 «Солнышко»», группы с понятными названиями.
  - Миниатюры детей — нейтральные SVG-заглушки. Реальных фото и данных stage в базе знаний нет.
- **Образец PDF** — страница, собранная настоящим `MpdfSalesReportWriter` на тех же демо-данных.
- **Деплой** — frontend-only: образ из merge-коммита. Код приложения совпадает с живым (`main` после 40b44df меняет только документы и guide); бэкенд не трогаем.

## Scope

1. `/guide/reports/` — статья:
   - роли и область;
   - как открыть;
   - уровни и крошки;
   - плитки итогов;
   - дети группы и статусы;
   - печать по форматам;
   - PDF;
   - что считается продажей;
   - частые вопросы.
2. `/guide/` — плитка «Отчёты о продажах»; `team`, `curator`, `organizer` — строки и ссылки на статью; `faq` — пара вопросов про отчёт.
3. Скриншоты `r01…` в `frontend/public/guide/img/`.
4. Проверки:
   - ссылки и картинки guide существуют (как в `buyer-guide.test.mjs`);
   - `npm run check`;
   - визуальный просмотр;
   - полный гейт.
5. PR, merge и frontend-only выкладка по поручению владельца.
