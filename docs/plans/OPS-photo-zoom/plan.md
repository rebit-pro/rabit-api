# Увеличение фотографий в галереях

## Цель и контекст

Дать родителю и сотруднику возможность рассмотреть ребёнка на подготовленном превью. Сейчас родительская галерея и предпросмотр набора открывают кадр крупнее миниатюры, но не увеличивают его; в отчёте о продажах доступна только миниатюра. Пользователь подтвердил охват кабинета сотрудников и отчёта.

## Scope

- Управляемое увеличение и перемещение водяного превью в родительской галерее и предпросмотре набора сотрудника на телефоне и компьютере.
- Открытие и увеличение первого кадра ребёнка из отчёта, с теми же проверками доступа и передачи ссылки, что у миниатюры.
- Проверка остальных сеток с фотографиями в кабинете и добавление входа в крупный просмотр там, где его ещё нет.
- Доступные кнопки, клавиатура, сброс масштаба при смене кадра, запрет выдачи оригинала через новый просмотр.

## Вне scope

- Повышение разрешения подготовленного превью выше имеющихся 1200 px; доступ к оригиналам и скачивание.
- ФИО ребёнка в заказе и отчёте: отдельная независимая ветка.
- Аватары, декоративные изображения и статические иллюстрации инструкций.

## Зависимости и решения

- Base: `main` / `b57581611fa253dacac9480b84e4e44b78b3b948`. Ветка `codex/ops-photo-zoom`.
- Поиск GitHub issues и PR на 31.10.2026: прямого дубля нет; открытый #191 относится к отсутствию миниатюр на live-странице заказа, не к увеличению галереи.
- Текущий endpoint отчёта возвращает `thumb`; для крупного просмотра нужен вариант подготовленного `preview` под прежней проверкой прав.
- Обложка в кабинете может находиться вне текущей страницы кадров: её модель должна иметь оба адреса из уже действующего разрешённого источника (`thumb` и `preview`).
- Управляемый `v-dialog` без Vuetify activator не возвращает фокус на исходную кнопку во всех точках входа. Общий диалог должен запоминать открывший элемент и после закрытия возвращать ему фокус, если он ещё в DOM.
- Риск: превью ограничено 1200 px и водяным знаком; увеличение сверх исходного разрешения не добавляет деталей. Риск доступа к отчёту проверяется реальным HTTP E2E.
- `git fetch origin main` в текущей среде завис и был прерван; локальный `main` совпадает с `origin/main` на момент проверки. Перед PR повторить сверку base.

## Критерии приёмки

1. На каждом экране галереи с фото пользователь может открыть кадр и приблизить его, переместить увеличенную область и вернуть масштаб.
2. При смене кадра и закрытии масштаб сбрасывается; кнопки доступны с клавиатуры, на телефоне жест перемещения не прокручивает фон.
3. Отчёт показывает только водяное превью разрешённого ребёнка; чужой ребёнок и группа без переданной ссылки получают прежний отказ.
4. Оригиналы и ключи доступа не попадают в новый API-ответ или HTML.
