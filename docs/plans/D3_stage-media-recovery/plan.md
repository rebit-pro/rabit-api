# D3 — восстановление загрузки фотографий на stage

## Цель и контекст
Восстановить GET списка кадров и POST загрузки на app.morefoto36.ru после релиза E4. MediaController требует UploadPhotoUseCase при создании, а stage FPM не получил MESSENGER_TRANSPORT_DSN. Для обработки кадров нужен stage consumer. Отдельно выяснить HTTP 413.

## Scope
- Изолированная очередь stage в RabbitMQ, настройка stage FPM и consumer без изменения site_* приложения.
- Проверка DI, HTTP-контракта и обработки тестового файла.
- Уточнение документации логов stage.
- Поднять лимит тела запроса frontend nginx до 30 МБ и показать понятную ошибку при пустом/ошибочном ответе списка кадров.
- Issue о ZIP/импорте по ссылке.
- Уточнить ошибку F1 `INVALID_ROW` для кода снимка вне формата и не отправлять такой запрос.

## Вне scope
- Реализация ZIP/облачного импорта, изменение лимита 50, изменение бизнес-данных основного site_*.

## Зависимости, решения и риски
- Зависит от слитых D1/E4. Stage использует отдельный vhost и очередь, без общих сообщений с основным приложением.
- Настройка RabbitMQ и stage-сервисов должна иметь обратимые параметры. Секреты не записывать в репозиторий.
- HTTP 413 воспроизведён с телом 8 МБ на публичном домене; frontend nginx использует стандартный предел 1 МБ. Backend nginx уже разрешает 1000 МБ.

## Критерии приёмки
- GET /api/v1/shoots/{id}/photos возвращает корректный JSON при авторизации.
- POST файла допустимого формата/размера не получает 413; кадр проходит обработку или выдаёт предметную ошибку.
- Stage consumer работает, использует отдельную очередь и пишет диагностируемые логи.
- Основной site_* не изменён.

## Тест-кейсы
1. D3-DI: разрешить UploadPhotoUseCase через stage ServiceLocator; ожидается PASS. Команда: одноразовый `php` внутри stage FPM.
2. D3-HTTP-LIST: авторизованный GET группы; ожидается JSON items/meta. Команда: HTTP через app.morefoto36.ru.
3. D3-HTTP-UPLOAD: загрузить JPEG <25 МБ; ожидается 202 и обработка. Команда: браузерный E2E/HTTP.
4. D3-HTTP-LIMIT: загрузить JPEG 8 МБ; ожидается ответ приложения, не 413. Команда: HTTP через публичный домен.
5. D3-QUEUE: stage consumer и очередь подтверждены; команда: docker service ps/logs и rabbitmqctl list_queues в stage vhost.
6. D3-LOG: определить рабочий путь логов и проверить запись; команда: service logs/find runtime.
7. D3-F1-INVALID: ввести код `A0001`; ожидается подсказка формата в поле без POST. Команда: browser E2E.
