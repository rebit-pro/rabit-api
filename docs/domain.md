# Предметная граница RaBit API

Текущая основа содержит идентификацию пользователя (`rebit.auth`) и общие технические возможности (`rebit.share`). `rebit.notification` отвечает за приём заявок с сайта и их синхронную доставку в Telegram с резервным email. Самостоятельный действующий модуль `rebit.leadhunter` отвечает за поиск внешних заявок, правила отбора, дедупликацию и доставку лидов в Telegram с резервным email. Оба потока относятся к лидогенерации и сохранены в RaBit API; Notification не включён как готовая общая асинхронная система уведомлений. Торговые сущности, подключения к бирже, кошельки и сделки больше не входят в приложение.

Предметная область MoreFoto определяется в [документации соседнего проекта](../../MoreFoto/docs/README.md). Будущие модули, владение ресурсами, статусы и правила доступа реализуются по её согласованным контрактам. Существующая регистрация Auth не доказывает готовность ролей, организаций, приглашений или объектных прав MoreFoto.
