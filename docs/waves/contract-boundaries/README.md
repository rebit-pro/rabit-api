# Уточнение размещения контрактов

Общие технические контракты остаются в `rebit.share/lib/Application/Contract/`. Предметные межмодульные контракты размещаются в `rebit.share/lib/Contracts/<Domain>/`. Точное правило и namespace — в [актуальной архитектуре](../../architecture.md#контракты-и-di).

Это уточнение документации до предметных волн, отдельное от W01. PHP-файлы и namespace существующих контрактов не меняются. Примеры `Order`, `Payment`, `Media` описывают будущие контракты.

## Синхронизация MoreFoto

В соседнем `/home/user/MoreFoto` обновлены источники и результаты генерации документации модулей, W05 и REST-реестра. В этом каталоге нет Git-репозитория. Поэтому [точный diff](morefoto-documentation.patch) включён в данный PR для ревью изменений соседней документации; локально они уже применены. Patch сформирован без строк контекста; проверка обратного применения `git apply --check --reverse --unidiff-zero` прошла.

Метаданные реестра теперь различают `technicalContractsPath` и `domainContractsPath`. HTTP-операции и все Postman-файлы сохранены без изменений. Замороженный снимок W00 не переписывается; новые волны следуют актуальной архитектуре.

Проверено: генерация волн и REST-документации, существующий offline-валидатор, равенство всех 99 endpoint-записей и SHA-256 каждого Postman-файла до/после. Валидатор подтверждает 35 волн. PHP и production не затрагиваются.
