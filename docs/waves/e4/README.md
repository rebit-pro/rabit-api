# E4 — приватная галерея и серверная корзина

Ветка `codex/e4-private-storefront` от main `6b8164747e3ed3f6f73a7a91efc0d28b2eb365bc`. Зависимости D2/E3/F1 слиты; F1 завершена PR #25. E4 реализует MED-01, COM-08 и COM-09 в morefoto.media/morefoto.commerce. План и журнал: `docs/plans/E4_private-storefront/`.

Покупатель открывает приватную ссылку, видит разрешённые фотографии и выбирает продукцию. Корзина сохраняет только выбор; цены, скидки и подарки рассчитывает сервер по SalesPolicy E3. Один снимок у двух детей получает разные assignmentId: пороги подарка не складываются между детьми.

## Контракты и границы

- MED-01: `GET /api/v1/public/galleries/{gallery_token}`. Capability — 32 случайных байта, в БД SHA-256. Внутренний GalleryCapabilityLifecycle выдаёт/отзывает ключ, не меняя сроки группы. Preparing скрывает фото, open разрешает quote, closed сохраняет просмотр и запрещает новый quote. Публичная передача ссылки — F2.
- COM-08: `GET .../catalog`. Активные товары и условия конкретной группы. `receiptChannels=[]`, `purchaseEnabled=false`: наличие Notification H1 не означает готовую фискализацию.
- COM-09: `POST .../quotes`, тело `{lines:[{assignmentId,productId,quantity}]}`. Неизвестные поля, чужие связи/товары, повторные строки и неверные количества отклоняются. До 100 строк; физическая продукция 1–99, цифровая — 1. Bundle выбирает ребёнка по assignmentId; отдельный digital вместе с его bundle запрещён.
- Quote действует 15 минут. Fingerprint связывает состав, назначения/версии фото, группу, capability revision, каталог/условия и подтверждение льготы. Create/ValidateQuoteUseCase работают через SERIALIZABLE-транзакцию; внутренний executeWithinTransaction предназначен для будущей атомарной операции заказа E5. Сырой ключ и URL превью не сохраняются в snapshot.
- Льгота staff-группы требует серверного подтверждения Handoff для каждого выбранного ребёнка этой съёмки. Клиентский флаг не принимается.
- DTO пассивные; action принимает один RequestDto. HTTP-обвязка общая, преобразование в API вынесено в mapper. Commerce bootstrap явно подключает поставщиков межмодульных портов.

## Защищённые изображения и frontend

Превью выдаются через capability `/api/v1/public/galleries/{token}/photos/{assignmentId}/{thumb|preview}` либо авторизованный `/api/v1/photos/{photoId}/{thumb|preview}`. Каждый запрос проверяет доступ, ответ `image/webp`, `no-store`. Оригиналы не выдаются. Прямой `/upload/morefoto/previews/` закрыт nginx; административный PhotoImage получает Blob с Bearer и освобождает object URL.

Live-сборка использует настоящий API для `/g/:token` и `/g/:token/cart`. Серверный итог повторно запрашивается после изменения количества и перезагрузки. При сетевом сбое выбор сохраняется; интерфейс предлагает повтор/очистку, не показывает непроверенный итог как актуальный. Gallery/Cart не используют demo storage. Checkout, заказы и платежи остаются недоступными до E5/G2.

Nginx исключает пути capability из access log; HTML/API запрещают передачу Referer. Тестовые ключи и traces не коммитятся. Снимки визуальной проверки содержат только искусственные изображения и тестовые названия.

## Проверки

Полный gate: backend/frontend PASS, browser 56 PASS / 1 FAIL. Старый D1 тест (zz-media.spec.ts:101) ожидает анонимный GET превью 200, новый защищённый маршрут отвечает 401. Draft PR не готов к merge: требуется обновить проверку на anonymous 401 / Bearer 200 и повторить полный gate. Финальный post-browser verifier не выполнялся из-за этого FAIL. Факты — verification.json. Адресно прошли 6 браузерных сценариев; четыре desktop/mobile снимка просмотрены. Дополнительный real MySQL сценарий проверяет свежий quote, подмену области/состава, смену цены/версии/назначения, TTL, отзыв, отсутствие сырых ключей в snapshot, идемпотентность назначения и повтор миграции.

Воспроизводимая команда из корня checkout:

```sh
make test-e2e E2E_PHP_CLI_IMAGE=rabit-api-php-cli:d1-local E2E_PHP_FPM_IMAGE=rabit-api-php-fpm:d1-local E2E_KERNEL_ROOT=/home/user/rebit-p2p/api/public/bitrix E2E_VENDOR_ROOT=/home/user/rabit-api/api/vendor
```

Путь rebit-p2p здесь — только источник лицензированного ядра для disposable fixture. Код и Composer-зависимости берутся из rabit-api. CI отключён, результаты локальные. DAG/99 API/независимая готовность проверяются `python3 tools/verify-wave-graph.py docs/waves/graph.json`.

## Подключение и ограничения

Миграции foundation: `20260921130001` (постоянный assignment UUID, capability), `20260921140001` (quote). Backfill заполняет только отсутствующие UUID; повтор не меняет существующие. Откат приложения сохраняет эти данные; down не удаляет используемые идентификаторы/quote.

Для подключения нужны согласованные backend/frontend/nginx версии: закрытие прямых файлов и новая авторизованная выдача применяются вместе. Контракт соседнего MoreFoto уточнён по решению пользователя; воспроизводимый diff генераторов — `morefoto-contract.patch`. Соседний каталог не является Git checkout.

Проверки выполняются только на искусственных данных. Публичная выдача покупательских ссылок требует F2, реальные продажи — N2. Заказ/оплата E5/G2, перенос D3 и deployment не входят в E4. Автоматическая очистка истёкших quote пока не реализована; истечение строго блокирует использование токена, но не удаляет строку хранения.
