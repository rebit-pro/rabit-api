# Ограничения C3

- C3 не сдана: реальный frontend редактор и браузерная/визуальная приёмка ждут отдельно разрешённого merge A8 PR14. Native HTTP seam не заменяет E2E в браузере.
- C2 до этой волны уже не передавала reason в контракте замены куратора/руководителя, хотя D08 требует причину. C3 добавляет обязательную причину только в своём сценарии воспитателя; исправление внешних ORG-03/05 остаётся отдельным согласованным изменением.
- Полный PHPUnit проходит, но существующий serializer выводит два предупреждения о кешировании не-readonly DtoClassMetadata/DtoParameterMetadata без clone. Эта волна их не меняет.
- Окружение: Docker Desktop 4.71.0 повторно создаёт недоступные AF_UNIX сокеты после рестарта; текущее восстановление выполнено с резервированием каталогов. Заводской сброс и удаление данных не применялись.
- Параллельный PHPStan получил exit137 при лимите1GiB; полный однопроцессный анализ завершился без ошибок. Это ограничение локального запуска, не пропуск анализа.
