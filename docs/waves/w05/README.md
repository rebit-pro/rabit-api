## Подтверждённые основания и предложения

Из ранее записанных ответов: родителю не нужна регистрация; группы разделяют заказы; повторные покупки разрешены; приём длится семь дней от фактической передачи ссылки; продление согласуется с куратором; доставка — семь дней от актуального закрытия; учреждению нужны количество заказов и сумма без контактов родителей. Есть месяц скачивания, но его точное начало/граница требуют D10.

R16 показывает работоспособность сценариев на моках. R17 подготовлен, результаты бизнеса не получены. Матрица ролей, числовые сроки ключей, способ выдачи учётки и форма summary ниже — предложения для согласования. Цены, провайдеры и правила возврата из моков не утверждаются.
