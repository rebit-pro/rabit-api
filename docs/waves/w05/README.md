## Подтверждённые основания

Из ранее записанных ответов: родителю не нужна регистрация; группы разделяют заказы; повторные покупки разрешены; приём длится семь дней от фактической передачи ссылки; продление согласуется с куратором; доставка — семь дней от актуального закрытия; учреждению нужны количество заказов и сумма без контактов родителей. По принятому D10 месяц скачивания отсчитывается от первого подтверждённого paidAt до того же местного времени с ограничением последним днём целевого месяца.

R16 показывает работоспособность сценариев на моках. Подтверждения B01–B14 представителем бизнеса по-прежнему нет; оно не выдумывается. Отдельным ответом пользователь принял модель и разрешил реализацию по рекомендациям. Это снимает прежнее ожидание R17 как запрет на разработку W06–W09; бизнес-приёмка интерфейса остаётся условием выпуска, а не причиной простаивать на документации.
