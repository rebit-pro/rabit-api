# Карта прежних WNN

Все прежние ID сохранены. Разделённая WNN завершена только после всех указанных срезов; основной владелец каждого endpoint ровно один.

| --- | --- | --- |
| W00 | A1 | Зафиксировать исходный состав и контракты |
| W01 | A2 | Убрать секреты из HTTP-логов |
| W02 | A3 | Закрыть дефекты срока и отзыва сессии |
| W03 | A4 | Исправить общий multipart и принадлежность загрузки |
| W04 | A5 | Сделать подключение модулей и окружения воспроизводимым |
| W05 | A6 | Утвердить предметные границы и схему первого среза |
| W06 | B1 | Профиль и серверная проверка доступа |
| W07 | C1, C2, C4 | Учреждения: внутренние сценарии и хранение; Учреждения: защищённые команды и назначения; Полная карточка учреждения |
| W08 | C3 | Съёмки, группы и календарь |
| W09 | B2 | Сотрудники и назначения |
