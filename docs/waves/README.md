Каждая волна — самостоятельный PR от актуального `main` в `main`. Все её необходимые runtime, compile и schema зависимости уже должны быть в main. Готовые волны берём одновременно; заблокированные пропускаем. Stacked PR, перенос незамерженного соседнего кода и фиктивные поставщики запрещены. Проверка проводится на main плюс только собственный diff. После обновления base повторяются затронутые проверки; перед merge обязательны реальные E2E и визуальная проверка затронутого интерфейса; deployment остаётся отдельным действием.

Буква — направление, номер — самостоятельный срез. Новые ссылки: [карта A–N](a7/README.md), [активный граф и границы](graph.json), [соответствие всем WNN](a7/legacy-map.md). Исторические отчёты сохраняют прежние имена. `unlocks` означает прямых потребителей; начать их можно лишь после merge всех `dependsOn` и решения затрагивающих их вопросов.
