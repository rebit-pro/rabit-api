# J4 — цифровая копия оплаченного печатного кадра

Ветка `codex/j4-print-digital-copy` от main `a302774` (merge E8, PR #181). Зависимости E5, G1, J1 и E7 слиты, решения D07/D10 приняты. План и журнал: `docs/plans/J4_print-digital-copy/`. Требование R03 из плана владельца `docs/plans/OPS-telemos-feedback-plan/`.

Подтверждённая покупка печати даёт скачивание каждого оплаченного кадра — по одному и в ZIP — без доплаты. Несколько отпечатков и форматов одного кадра дают один файл. Соседние кадры ребёнка не открываются. Цена, количество и снимок заказа не меняются. Комплект (`bundle`) и подарок по порогу печати (`GIFTS`) работают по прежнему правилу J1: все текущие готовые кадры ребёнка. Срок — прежний месяц J1 от первой оплаты (D10).

## Решения (12.10.2026)

- **J4-DEC-01.** Право действует для всех оплаченных заказов с печатью, в том числе оплаченных до выкладки. Рассылки нет, снимки заказов не меняются. Заказы старше месяца от оплаты остаются `expired`. Закрывает MVP-PRINT-COPY-HISTORY.
- **J4-DEC-02.** Новая редакция оферты 2026-10-12:
  - п. 27 — покупатель указывает только email (исправление после E8);
  - новый пункт раздела 6 — электронная копия каждой фотографии, по которой оплачена фотопродукция.
- **J4-DEC-03.** В выборе продукции электронного фото кадра, печать которого уже в корзине, показывается «Электронная копия этого кадра входит в печать вашей корзины». Цена и расчёт не меняются, добавление не блокируется.
- **J4-DEC-04.** E2E оплаченной печати — оплата фикстурой стенда вместо тестового магазина ЮKassa (см. «Проверки»).

## Выкладка

Миграций нет. Релиз из main после J4 включает E7, D4, E8 и J4 вместе; порядок их миграций — в README этих волн.

Перед выкладкой — preview влияния на существующие заказы (J4-DEC-01). Это верхняя оценка: кадры, уже открытые `digital`/`bundle`/подарком, тоже посчитаны.

```sql
SELECT COUNT(DISTINCT o.ID) AS orders, COUNT(DISTINCT o.ID, l.PHOTO_PUBLIC_ID) AS frames
FROM mf_order o JOIN mf_order_line l ON l.ORDER_ID = o.ID
WHERE o.PAYMENT_STATUS = 'paid' AND o.LATE_PAYMENT = 0 AND l.PRODUCT_KIND = 'physical'
  AND o.PAID_AT > UTC_TIMESTAMP() - INTERVAL 1 MONTH;
```

Откат — возврат кода; данных J4 не пишет. Уже выданные загрузки и архивы истекают по правилам J1.
