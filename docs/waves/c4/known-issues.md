# Ограничения и проверки C4

- Финансовый provider ещё не реализован; summary возвращает согласованный unavailable/dependenciesNotReady, без выдуманных сумм. Финансовый ready требует N1 и повторной проверки.
- Имена сотрудников пока не выдаются настоящим контрактом C2/C4: интерфейс показывает фактические ID назначений. Служебные формы B2 и выбор воспитателя остаются отдельной волной.
- Group detail ORG-11 ещё не подключён. Организатор открывает группу через её съёмку; куратор/руководитель видят структурные списки без ссылок в organizer-only редактор.
- Прежние дефекты A8 pending после lost-response→401/403 и C2 replacement reason не входят в C4; см. ../c3/known-issues.md.

## Предварительные неуспешные проверки

Первый полный up прошёл frontend check/unit/build, но остановился на PHPStan из-за @var перед ещё не объявленной переменной $row. Аннотация перенесена после fetch без suppressions; стенд автоматически очищен. Это не зелёный полный прогон, финальный результат фиксируется отдельно.

Два ранних native C4 запуска исправляли ошибки нового тестового HTTP транспорта: namespace Server и обработку null результата Bitrix run через finalizeResponse. Оба сохранены локально; итоговый native C4 прошёл 99 проверок. Старый standalone PHPUnit использовал устаревший root/vendor autoload и не засчитывается: обязательный запуск пересобирает Composer autoload для C4.

Первое frontend форматирование запущено с default Prettier, расходящимся с проектными ESLint rules; применён штатный ESLint --fix. Из прежнего C3 E2E удалены случайные правки форматирования.

Vite сохраняет прежнее предупреждение об отсутствующем auth-pattern-dark.svg. Экраны MoreFoto используют светлую тему. Два прежних предупреждения metadata caching в PHPUnit не маскируются.
