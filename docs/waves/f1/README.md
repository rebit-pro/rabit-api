## Результат волны

Добавлен модуль `morefoto.handoff` и реальные HND-06/07/08/09/12 endpoints для списка, создания, карточки, повторной подачи и запроса уточнения. Заявка хранит UUID, строки детей, серверный снимок подтверждённого права сотрудника, revision, историю переходов и идемпотентный результат.

Access заново подтверждает роль и текущие назначения на каждом запросе. Organization разрешает внутренние ID только после проверки связей учреждения, съёмки и обычной группы. Media разрешает введённый код ребёнка или снимка только внутри этой области и возвращает готовые фотографии. Чужая область маскируется как 404; неподтверждённый сотрудник получает 403; stale revision и повтор ключа с другим телом — 409.

Проверка активной заявки сериализуется блокировкой строки ребёнка внутри транзакции. После будущего перехода в `transferred` ребёнок может участвовать в новой заявке, поэтому схема использует индекс, а не вечный unique. Live frontend использует реальный API, поддерживает несколько назначений воспитателя, показывает подтверждённое сервером право и полную историю. Перенос фотографий и preview HND-10/11 намеренно не активированы: это граница D3.
