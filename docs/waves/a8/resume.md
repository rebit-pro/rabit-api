Постоянный worktree: `/home/user/rebit-p2p/api/var/worktrees/a8`, ветка `codex/a8-real-e2e`. Основной checkout остаётся на main. Не создавать worktree в `/tmp`: незакоммиченные файлы прошлой попытки исчезли после перезапуска WSL.

Docker Desktop падает на служебном сокете `dockerInference`; движок недоступен. Принудительная остановка отклонена автоматической проверкой разрешений из-за общего воздействия на контейнеры. Явное разрешение пользователя запрошено. Не обходить этот отказ.

После восстановления Docker:

1. Сверить `origin/main` с base из verification.json. Не добавлять код незамерженных волн.
2. Выполнить форматирование трёх изменённых PHP-файлов конфигом проекта на PHP 8.4, PHPUnit/PHPStan и native каталог `api/tools/run-e2-catalog-integration.sh` с kernel/vendor из основного checkout.
3. Выполнить `make e2e-up` и `make e2e-test E2E_STATE=<напечатанный путь>` на новой БД. Сделать визуальную проверку desktop/mobile, затем `make e2e-down`.
4. Выполнить demo Cucumber отдельно с 1–2 workers и доступным браузером. `--network none` делает navigator.onLine=false и ломает demo; использовать изолированную внутреннюю сеть.
5. Обновить verification.json, README/PR фактическими результатами. Исторические 13 E2E не считать текущим подтверждением. Новые PR автоматически не сливать.
