# Неблокирующие замечания A8

- Неверный пароль отклоняется сервером, но текущий текст ошибки API отображается как `Invalid credentials`. Мобильная форма показывает его без обрезания, повторный вход работает. Локализация ошибки — отдельное улучшение.
- Существующий `frontend/src/scss/layout/_dark.scss` ссылается на отсутствующий `auth-pattern-dark.svg`. Production build сообщает об этом. Текущий live-вход использует другую разметку; проверенный браузерный сценарий не делает неуспешных запросов ресурсов.
- Унаследованный `vite-plugin-inspect` 0.8.9 через devtools объявляет peer Vite 5/6 при имеющемся Vite 7.2.2. Lock-файл сохранён; install, check и production build проходят. Обновление зависимостей в A8 не включено.
- В ускоренном demo с двумя workers сценарий R12 «повтор ошибки не превышает изменившийся остаток» получил общую формулировку конфликта вместо ожидаемой конкретной. При повторе штатным одним worker он прошёл без изменения приложения. Причина расхождения не установлена; это сохранено как нестабильная demo-проверка, а не как исправленный дефект. Два отдельных визуальных падения имеют подтверждённый cgroup OOM.
